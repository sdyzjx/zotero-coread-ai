Recurrent models typically factor computation along the symbol positions, which precludes parallelization within training examples.

The fundamental constraint of sequential computation, however, remains.

3.2.1 Scaled Dot-Product Attention

We compute the matrix of outputs as Attention(Q, K, V) = softmax(QKT/√dk)V. We suspect that for large values of dk, the dot products grow large in magnitude…

AI 伴读
为什么要除以 √dk？
维度大时点积方差随 dk 增长，softmax 会饱和、梯度变小；除以 √dk 把方差拉回 1。 p. 4
问题

让 AI 替你读论文，信息丢在了哪里

把 PDF 丢给聊天机器人、拿回一页摘要，看起来省时间。可一篇论文最有价值的部分，恰恰是摘要最先删掉的部分。

压缩

二十页压成五条要点

实验条件、适用范围、限定语和负面结果最先被删掉。你拿到的是结论别人对结论的转述。

脱离原文

回答没有出处，无法核对

没有页码，没有原句。正确的概括和编造的细节混在一起，读者分辨不出来。

截断

长论文只读了前半篇

上下文放不下全文时，附录、消融实验和图表最容易被悄悄截掉，回答却照样自信。

留不下来

读完就散在聊天记录里

理解停留在一次对话中，不在 PDF 上，也不在文献库里。下次打开论文，一切从头开始。

旁注AI 读得再快，读论文的仍然应该是你。CoRead AI 的目标是让你读得更准、更快，并且读过的东西留得下来。
做法

协同精读：AI 指路，你来读，结果留在原文上

引导注意力先看清结构，再决定读哪里

点「生成文章脉络」，左侧会长出一棵按逻辑角色组织的论文结构树。每个节点都锚定到原文中的具体句子，点一下就跳过去并高亮。

  • 研究论文按 背景 → 问题 → Gap → 方法 → 实验 → 结果 → 结论 展开，综述梳理发展脉络与研究分支
  • 第一章逐句拆解摘要，告诉你每句话在论证里的作用
  • 重点句在 PDF 上标出，一键存为高亮
背景 Gap 方法 实验 结果 结论

角色颜色取自 Zotero 标准批注色，保存的高亮可以直接在批注侧栏按颜色筛选。

AI 原生辅助阅读在读的地方提问，不离开 PDF

选中一句话，选区下方就有 AI 按钮；框选一张图、一个公式或表格，直接问它。回答带可点击的页码，点一下回到原文。

  • 划词：解释 / 翻译 / 总结 / 问 AI / 引用到聊天，操作可自定义
  • 框图提问 ⌘/Ctrl Shift K：AI 真正“看”图，而不是猜
  • 文章级对话 ⌘/Ctrl Shift L：Agent 先看概览，再检索、再精读需要的页，不把全文硬塞进上下文
  • 可以查阅文献库里的其他论文、你的历史批注和之前会话的结论

模型

用你已经有的 AI

可以填 DeepSeek API Key，也可以直接调用本机已经登录的命令行 Agent。在设置里点一下切换默认来源，聊天中途也能换模型，对话记录会接着用。

DeepSeek API

填入 API Key，按量计费。默认 V4.1 Flash，可加其他模型。

deepseek-flash

Claude Code

调用本机 claude，使用它的登录账号与额度。

claude-code:sonnet

Codex

调用本机 codex，使用你的 ChatGPT / OpenAI 登录。

codex

Antigravity

调用本机 agy，在设置里一键安装 Zotero 工具插件。

agy:gemini-3.8-flash-medium
旁注命令行 Agent 通过 Zotero 本地服务（仅 127.0.0.1，MCP 协议）使用和内置 Agent 完全相同的工具。它们以受限权限运行：Claude Code 关闭自带的 shell 与文件工具，Codex 使用只读沙箱，每篇论文有独立的工作目录。
安装

三分钟装好

  1. 下载插件

    需要 Zotero 7、8、9 或 10。插件之后会自动从本站检查更新。

    下载 v{{VERSION}} coread-ai-{{VERSION}}.xpi · {{SIZE}} SHA-256 {{SHA256}}

  2. 在 Zotero 中安装

    打开 Zotero，菜单 工具 → 插件，点右上角齿轮，选 从文件安装插件…，选择刚下载的 .xpi。如果浏览器把它当成网页扩展打开，请改用右键「另存为」。

  3. 选择模型来源

    打开 Zotero 设置 → CoRead AI（或 工具 → CoRead AI 设置…）：

    · DeepSeek：在「模型来源」填入 API Key，点「测试连接」。
    · Claude Code / Codex / Antigravity：先在终端装好并登录对应 CLI，然后在对应标签页点「检测」和「设为默认来源」。Antigravity 还需点一次「安装插件」。

  4. 打开一篇论文开始读

    在阅读器左侧点「生成文章脉络」；选中文字用 AI 按钮；⌘/Ctrl Shift L 打开聊天面板，⌘/Ctrl Shift K 框图提问。

我的数据会发到哪里？

论文内容只发给你选择的模型来源：DeepSeek API，或你本机登录的 Claude Code / Codex / Antigravity。API Key 保存在 Zotero 本地偏好设置中；插件提供给 CLI 的工具服务只监听 127.0.0.1，每轮对话使用一次性地址。

要花多少钱？

插件免费开源。DeepSeek 按 API 用量计费；CLI 来源使用你在对应服务的订阅或额度。网络搜索默认用 DeepSeek 搜索，也可以换成免费的 DuckDuckGo。

扫描版 PDF 能用吗？

文章脉络、检索和自动高亮依赖 PDF 的文字层。扫描件请先做 OCR；框图提问不受影响，AI 直接看图。
